# How the SDK Handles Multicast - Complete Code Flow

## Overview

This document shows **exactly how the SDK handles multicast** when Skylink (or any application) configures video streaming. The SDK itself doesn't "do" video streaming - it **configures the gimbal** to stream video, and the gimbal does the actual streaming.

## Architecture Flow

```
Skylink Application
    ↓
SDK: encodeOrionNetworkVideoPacketStructure()
    ↓
SDK: OrionCommSend() → Sends packet to gimbal
    ↓
Gimbal: Receives OrionNetworkVideo packet
    ↓
Gimbal: Interprets DestIp, Port, Ttl fields
    ↓
Gimbal: Starts UDP video streaming to DestIp:Port with TTL
    ↓
Multiple Receivers: Skylink, VideoPlayer, FFmpeg scripts receive stream
```

## Step-by-Step Code Flow

### Step 1: Protocol Definition (What the Gimbal Understands)

**File**: `Communications/OrionPublicProtocol.xml`

```xml
<Packet name="OrionNetworkVideo" ID="ORION_PKT_NETWORK_VIDEO" 
        comment="Change the IP settings for video delivery.">
    
    <Data name="DestIp" inMemoryType="unsigned32" 
          comment="destination IPv4 address"/>
    
    <Data name="Port" inMemoryType="unsigned16" 
          comment="destination port"/>
    
    <Data name="Ttl" inMemoryType="signed8" default="-1" 
          comment="TTL value for UDP video packets. 
                   Values less than or equal to zero will use default values 
                   of 64 for unicast and 1 for multicast." />
    
    <Data name="StreamType" enum="StreamType_t" encodedType="unsigned8" 
          default="STREAM_TYPE_H264" 
          comment="Output stream format specifier" />
    
    <!-- ... other fields ... -->
</Packet>
```

**Key Point**: The protocol defines `Ttl` with default `-1`, meaning:
- `Ttl = -1`: Gimbal **auto-detects** multicast vs unicast
- `Ttl = 1`: Explicit multicast TTL
- `Ttl = 64`: Explicit unicast TTL

### Step 2: Structure Definition (Generated by ProtoGen)

The SDK uses ProtoGen to generate C structures from the XML. The generated structure looks like:

```c
typedef struct
{
    uint32_t DestIp;      // Network byte order IP address
    uint16_t Port;        // UDP port
    int8_t   Ttl;         // TTL: -1=auto, 1=multicast, 64=unicast
    uint8_t  StreamType;  // STREAM_TYPE_H264, etc.
    uint32_t Bitrate;     // Bitrate in bits per second
    // ... other fields ...
} OrionNetworkVideo_t;
```

### Step 4: Multicast Detection Helper (Our Addition)

**File**: `Examples/VideoPlayer/NetworkVideoConfig.h`

```c
/**
 * Check if an IP address is in the multicast range (224.0.0.0 - 239.255.255.255)
 */
static inline int IsMulticastIp(uint32_t Ip)
{
    // Extract the first octet from the IP address (network byte order)
    uint8_t FirstOctet = (Ip >> 24) & 0xFF;
    
    // Check if first octet is in multicast range (224-239)
    return (FirstOctet >= 224 && FirstOctet <= 239);
}

/**
 * Configure OrionNetworkVideo_t structure with proper settings for multicast/unicast
 * 
 * This function automatically detects if the destination IP is multicast and configures
 * the TTL appropriately. It should be called before encodeOrionNetworkVideoPacketStructure().
 */
static inline void ConfigureNetworkVideoForMulticast(OrionNetworkVideo_t *pSettings)
{
    if (pSettings == NULL)
        return;
    
    // If this is a multicast address, explicitly set TTL to 1
    if (IsMulticastIp(pSettings->DestIp))
    {
        pSettings->Ttl = 1;  // Multicast TTL
    }
    // For unicast, we leave TTL at -1 (default)
    // The gimbal will use its default unicast TTL=64
}
```

**How It Works**:
1. Extracts first octet from IP address (network byte order)
2. Checks if it's in range 224-239 (multicast range)
3. Sets `Ttl = 1` if multicast, leaves `-1` for unicast

### Step 5: Packet Encoding (SDK Generated Code)

The `encodeOrionNetworkVideoPacketStructure()` function is **generated by ProtoGen** from the XML. It:

1. Takes the `OrionNetworkVideo_t` structure
2. Serializes each field according to the protocol definition
3. Packs it into a `TrilliumPkt_t` packet structure

**Pseudo-code** (actual implementation is generated):
```c
void encodeOrionNetworkVideoPacketStructure(OrionPkt_t *pkt, 
                                             const OrionNetworkVideo_t *settings)
{
    // Set packet ID
    pkt->ID = ORION_PKT_NETWORK_VIDEO;
    
    // Encode DestIp (uint32_t, network byte order)
    encode_uint32(pkt, settings->DestIp);
    
    // Encode Port (uint16_t)
    encode_uint16(pkt, settings->Port);
    
    // Encode Ttl (int8_t) - THIS IS WHERE TTL IS SENT TO GIMBAL
    encode_int8(pkt, settings->Ttl);
    
    // Encode StreamType (uint8_t)
    encode_uint8(pkt, settings->StreamType);
    
    // ... encode other fields ...
    
    // Set packet length
    pkt->Length = <calculated_length>;
}
```

**Key Point**: The `Ttl` field value (whether `-1`, `1`, or `64`) is **encoded and sent to the gimbal** exactly as set in the structure.

### Step 6: Packet Transmission (SDK Communication Layer)

**File**: `Communications/OrionComm.h` (implementation in `OrionCommLinux.c` or `OrionCommWindows.c`)

```c
// Simplified version
void OrionCommSend(const OrionPkt_t *pkt)
{
    // Send packet over TCP/UDP to gimbal
    // The gimbal receives this packet and processes it
    send(socket, pkt, pkt->Length + ORION_PKT_OVERHEAD, 0);
}
```

### Step 7: Gimbal Processing (On Gimbal Firmware)

**Note**: This is **gimbal firmware code** (not in this SDK), but here's what happens:

```c
// Gimbal firmware pseudo-code
void ProcessOrionNetworkVideoPacket(const OrionNetworkVideo_t *settings)
{
    uint32_t destIp = settings->DestIp;
    uint16_t port = settings->Port;
    int8_t ttl = settings->Ttl;
    
    // If TTL is -1 (default), auto-detect multicast
    if (ttl <= 0)
    {
        // Check if DestIp is in multicast range (224.0.0.0 - 239.255.255.255)
        uint8_t firstOctet = (destIp >> 24) & 0xFF;
        if (firstOctet >= 224 && firstOctet <= 239)
        {
            ttl = 1;  // Multicast default
        }
        else
        {
            ttl = 64;  // Unicast default
        }
    }
    
    // Configure UDP socket for video streaming
    ConfigureVideoStream(destIp, port, ttl);
    
    // Start streaming video to DestIp:Port with TTL
    StartVideoStream();
}
```

**Key Point**: The gimbal:
1. Receives the `OrionNetworkVideo` packet
2. Reads `DestIp`, `Port`, `Ttl` fields
3. If `Ttl = -1`, auto-detects multicast vs unicast
4. Configures UDP socket with proper TTL
5. Starts streaming video packets

### Step 8: Video Stream Reception (Receiver Side)

**File**: `Examples/VideoPlayer/StreamDecoder.c`

```c
int StreamOpen(const char *pUrl, const char *pRecordPath)
{
    // ... FFmpeg initialization ...
    
    AVDictionary *pOptions = 0;
    av_dict_set(&pOptions, "timeout", "5000000", 0);
    
    // ============================================
    // MULTICAST RECEIVER CONFIGURATION
    // ============================================
    // Detect if URL is multicast (e.g., "udp://239.255.1.1:15004")
    if (IsMulticastAddress(pUrl))
    {
        // Configure FFmpeg for multicast reception
        av_dict_set(&pOptions, "reuse", "1", 0);           // Allow multiple receivers
        av_dict_set(&pOptions, "fifo_size", "5000000", 0); // 5MB buffer
        av_dict_set(&pOptions, "buffer_size", "2097152", 0); // 2MB socket buffer
        av_dict_set(&pOptions, "overrun_nonfatal", "1", 0);  // Handle overruns gracefully
        av_dict_set(&pOptions, "ttl", "1", 0);              // Multicast TTL
    }
    
    // Open the stream
    avformat_open_input(&pInputContext, pUrl, NULL, &pOptions);
    
    // ... rest of initialization ...
}
```

**How Multicast Detection Works**:
```c
static int IsMulticastAddress(const char *pUrl)
{
    // Check if URL starts with udp://
    if (strncmp(pUrl, "udp://", 6) != 0)
        return 0;
    
    // Extract IP address from URL (format: udp://ip:port or udp://@ip:port)
    const char *pIpStart = pUrl + 6;
    if (*pIpStart == '@')
        pIpStart++;  // Skip @ if present
    
    // Parse IP address
    unsigned int octets[4];
    if (sscanf(pIpStart, "%3u.%3u.%3u.%3u", 
               &octets[0], &octets[1], &octets[2], &octets[3]) != 4)
        return 0;
    
    // Check if first octet is in multicast range (224-239)
    return (octets[0] >= 224 && octets[0] <= 239);
}
```

## Complete Example: Skylink Using Multicast

Here's how Skylink would use the SDK to configure multicast streaming:

```c
// Skylink application code (pseudo-code)
#include "OrionPublicPacket.h"
#include "NetworkVideoConfig.h"  // Include our helper
#include "OrionComm.h"

void ConfigureVideoStream(const char *multicastIp, uint16_t port)
{
    OrionNetworkVideo_t settings;
    OrionPkt_t pkt;
    
    // Initialize
    memset(&settings, 0, sizeof(settings));
    
    // Set destination to multicast IP
    settings.DestIp = inet_addr(multicastIp);  // e.g., "239.255.1.1"
    settings.Port = port;                       // e.g., 15004
    settings.StreamType = STREAM_TYPE_H264;
    
    // ============================================
    // AUTOMATIC MULTICAST CONFIGURATION
    // ============================================
    // This detects multicast and sets Ttl = 1 automatically
    ConfigureNetworkVideoForMulticast(&settings);
    
    // After this call:
    // - If multicast IP (224.x.x.x - 239.x.x.x): settings.Ttl = 1
    // - If unicast IP: settings.Ttl = -1 (gimbal will use default)
    
    // Encode and send to gimbal
    encodeOrionNetworkVideoPacketStructure(&pkt, &settings);
    OrionCommSend(&pkt);
    
    // Gimbal receives packet and starts streaming to multicast IP:port with TTL=1
    // Multiple receivers can now receive the stream
}
```

## How the SDK "Handles" Multicast

The SDK handles multicast in **two places**:

### 1. **Sender Configuration** (Gimbal Side)
- **Location**: `NetworkVideoConfig.h` → `ConfigureNetworkVideoForMulticast()`
- **What it does**: Detects multicast IPs and sets `Ttl = 1` in `OrionNetworkVideo_t`
- **When**: Before calling `encodeOrionNetworkVideoPacketStructure()`
- **Result**: Gimbal receives packet with `Ttl = 1` for multicast

### 2. **Receiver Configuration** (Application Side)
- **Location**: `StreamDecoder.c` → `StreamOpen()`
- **What it does**: Detects multicast URLs and configures FFmpeg with multicast socket options
- **When**: When opening video stream for reception
- **Result**: Multiple receivers can bind to same multicast address/port

## Key Code Locations

| Component | File | Function | Purpose |
|-----------|------|----------|---------|
| **Protocol Definition** | `Communications/OrionPublicProtocol.xml` | XML definition | Defines `Ttl` field with auto-detection |
| **Structure** | Generated by ProtoGen | `OrionNetworkVideo_t` | C structure with `DestIp`, `Port`, `Ttl` |
| **Multicast Detection** | `NetworkVideoConfig.h` | `IsMulticastIp()` | Detects multicast IPs (224-239) |
| **TTL Configuration** | `NetworkVideoConfig.h` | `ConfigureNetworkVideoForMulticast()` | Sets `Ttl = 1` for multicast |
| **Packet Encoding** | Generated by ProtoGen | `encodeOrionNetworkVideoPacketStructure()` | Encodes structure → packet |
| **Packet Sending** | `Communications/OrionComm.*` | `OrionCommSend()` | Sends packet to gimbal |
| **Receiver Config** | `StreamDecoder.c` | `StreamOpen()` | Configures FFmpeg for multicast |

## Summary

**The SDK handles multicast by**:

1. **Detecting multicast IPs** in the `DestIp` field
2. **Setting `Ttl = 1`** automatically before encoding
3. **Encoding the TTL value** into the packet sent to gimbal
4. **Configuring receivers** with multicast socket options

**The gimbal firmware**:
- Receives the packet
- Reads `Ttl` field (or auto-detects if `-1`)
- Configures UDP socket with proper TTL
- Streams video packets to `DestIp:Port`

**Applications (Skylink, VideoPlayer)**:
- Use `ConfigureNetworkVideoForMulticast()` before encoding
- Get automatic multicast TTL configuration
- Can receive multicast streams with proper socket options

This is a **client-side SDK** - it configures the gimbal, but the **gimbal firmware** does the actual video streaming.
